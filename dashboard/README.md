# Dashboard

Explorador bilingüe de los resultados del análisis fenológico. La aplicación
lee únicamente los productos compactos incluidos en `app_data/`; no descarga
ni procesa los datos geoespaciales originales durante su ejecución.

Desde la raíz del repositorio:

```bash
streamlit run dashboard/streamlit_app.py
```

En Streamlit Community Cloud, selecciona `dashboard/streamlit_app.py` como
archivo principal.
